# Diagrams

PlantUML source for the UML diagrams, generated by `omh codegraph uml` (codebase_uml/v1):
a package view (`codebase.puml`) and a module view (`modules.puml`).

To render them again (needs `java` + plantuml.jar):

```bat
java -jar plantuml.jar -tpng codebase.puml modules.puml
```

The PNG files are NOT kept in the repository: `tools/make_source_zip.py` refuses binary
files (so the source backup stays source only). Keep rendered images outside the repository.
